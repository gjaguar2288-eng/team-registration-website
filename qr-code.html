🚀 Step-by-Step Setup:

  1. Clone the repository:
    git clone https://github.com/gjaguar2288-eng/team-registration-website.git
  2. Navigate to folder:
    cd team-registration-website
  3. Install dependencies:
    npm install
  4. Start the server:
    npm start
  5. Open in browser:
    http://localhost:3000
  6. Scan this QR code with your phone camera - It will open the registration page!

⚙️ For Live Deployment:

When you deploy to production, update the URL in this file:

const websiteUrl = 'your-domain.com';

Then refresh this page to generate a new QR code pointing to your live website.
